# 💪 FitPlate Pro – Diet Tracker Web App

FitPlate Pro is a simple and effective **Diet & Nutrition Tracker** built using **HTML, CSS, and JavaScript**.
It helps users track daily calories, macros, and manage their fitness goals easily.

---

## ✨ Features

* 👤 User Profile Setup (Name + Goal)
* 🍽️ Add Custom Food Items
* 🔥 Track Calories Intake
* 🥩 Monitor Protein, Carbs, and Fats
* 📊 Real-time Daily Summary
* 📋 Food List Management
* ✅ Form Validation (Clean & Error-Free UI)

---

## 🛠️ Tech Stack

* HTML5
* CSS3
* JavaScript (Vanilla JS)
